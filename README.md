# LexiRead

An open-source e-reader app for Android supporting EPUB and PDF formats.

## Features
- Read EPUB and PDF files
- Offline dictionary
- Clean, distraction-free reading experience
- No ads, no tracking

## Download
Get it on [F-Droid](https://f-droid.org) (coming soon)

## Tech Stack
- Kotlin, MVVM, Clean Architecture
- Readium 3, Hilt, Room, Coroutines
