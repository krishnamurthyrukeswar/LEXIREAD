# Bundled Fonts

This directory should contain the following TTF font files for the reader:

1. **OpenDyslexic-Regular.ttf** — Dyslexia-friendly font
   - Download: https://opendyslexic.org/
   - License: SIL Open Font License

2. **Literata-Regular.ttf** — Google Fonts serif for reading
   - Download: https://fonts.google.com/specimen/Literata
   - License: SIL Open Font License

3. **Merriweather-Regular.ttf** — Google Fonts serif
   - Download: https://fonts.google.com/specimen/Merriweather
   - License: SIL Open Font License

4. **Lato-Regular.ttf** — Google Fonts sans-serif
   - Download: https://fonts.google.com/specimen/Lato
   - License: SIL Open Font License

5. **RobotoMono-Regular.ttf** — Google Fonts monospace
   - Download: https://fonts.google.com/specimen/Roboto+Mono
   - License: Apache License 2.0

## How to Install

Download each TTF file and place it in this `assets/fonts/` directory.
The app will gracefully fall back to system fonts if any file is missing.
